# SF340_A-care
#The objective is to collect health data such as BMI,
BMR, and TDEE, along with providing detailed
explanations of the calculations and information
related to diet and exercise. The main target group
is athletes who want to maintain their health. 

User feedback is collected to continuously improve
and update the versions, and change
management documentation for each version is
created following the QMR standard. 

The current version is 2.0.0.
